Bienvenue dans PureBasic OOP

PureBasic OOP apporte la puissance de la Programmation Orientée Objet complète à PureBasic grâce à un transpileur optimisé et une bibliothèque UI native moderne.

💡 Touche d'aide contextuelle F1

Dans l'IDE, placez votre curseur sur n'importe quel mot-clé POO (Class, Method, Super, Property...) ou composant UI (Window, Button, StackPanel, ListIcon...) et appuyez sur F1 pour ouvrir directement sa fiche d'aide détaillée !

Fonctionnalités Principales

  • Classes & Héritage Simple : Définition élégante avec Class ... Extends, surcharge de méthodes et appel parent Super::.
  • Surcharge de Constructeurs : Plusieurs constructeurs Init(...) par classe pour s'adapter à tous les usages (layouts automatiques ou fenêtres fixes).
  • Système de Layouts Responsifs (Style WPF) : StackPanel, DockPanel, Grid, Container avec dimensionnement Star (*), marges et alignements fluides.
  • Cycle de Vie Sécurisé : Instanciation par New et libération automatique ou manuelle via Free.
