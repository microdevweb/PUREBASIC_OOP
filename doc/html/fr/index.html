Documentation officielle du framework PureBasic Orienté Objet.

Bienvenue dans PureBasic OOP

PureBasic OOP apporte la puissance de la Programmation Orientée Objet complète à PureBasic grâce à un transpileur optimisé et une bibliothèque UI native moderne.

💡 Touche d'aide contextuelle F1

Dans l'IDE, placez votre curseur sur n'importe quel mot-clé POO (Class, Method, Super, Property...) ou composant UI (Window, Button, StackPanel, ListIcon...) et appuyez sur F1 pour ouvrir directement sa fiche d'aide détaillée avec son arbre d'héritage !
