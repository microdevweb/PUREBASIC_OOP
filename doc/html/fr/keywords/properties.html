Getters, Setters & Propriétés

Keyword

Encapsulation élégante des données membres.

Description

Les accesseurs Get et Set permettent de contrôler la lecture et l'écriture des champs internes tout en offrant une interface propre.

Syntaxe

Class CompteBancaire {
  Private solde.d
  
  Public Property Solde.d {
    Get { ProcedureReturn This\solde }
    Set(val.d) { If val >= 0 : This\solde = val : EndIf }
  }
}
