Héritage : Extends & Super

Keyword

Dérivation de classes et appel aux implémentations parentes.

Description

Le mot-clé Extends établit un lien d'héritage simple entre une classe dérivée et sa classe mère. Le mot-clé Super:: permet d'invoquer un constructeur ou une méthode de la classe parente.

Constructeurs Parents

Depuis la version 1.2, chaque classe enfant définit ses propres constructeurs Init(...) et appelle explicitement le constructeur parent souhaité :

Class Guerrier Extends Personnage {
  Public Method Init(nom.s) {
    Super::Init(nom, 150) ; Appelle Personnage::Init(nom, pv)
  }
}
