Extends / Super

Héritage

Héritage de classe et réutilisation de code parent.

Description

Le mot-clé Extends permet à une classe d'hériter des champs et méthodes d'une classe parente. Le mot-clé Super:: permet d'invoquer l'implémentation parente d'une méthode surchargée.

Exemple d'Héritage

Héritage et appel Super (.pbo)PBO
Class Vehicule
  Protected marque.s
  Public Method Demarrer()
    PrintN('Contact mis.')
  EndMethod
EndClass

Class Voiture Extends Vehicule
  Public Method Demarrer()
    Super::Demarrer()
    PrintN('Moteur V8 en route !')
  EndMethod
EndClass
