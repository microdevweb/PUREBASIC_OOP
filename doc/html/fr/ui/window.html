Classe Window

UI Class

Création flexible de fenêtres avec constructeurs multiples et accesseurs dynamiques.

Description

La classe UI::Window encapsule une fenêtre graphique native PureBasic avec support complet du responsive design, fermeture propre sans erreur et multiples constructeurs.

Constructeurs Surchargés

ConstructeurDescription
Init(title.s)Crée une fenêtre centrée 800×600 avec contrôles minimiser, maximiser et redimensionner.
Init(title.s, w.i, h.i)Fenêtre centrée avec largeur et hauteur personnalisées.
Init(title.s, w.i, h.i, flags.i)Fenêtre avec dimensions et flags PureBasic (ex: #PB_Window_Tool, #PB_Window_BorderLess).
Init(title.s, x.i, y.i, w.i, h.i)Position absolue et dimensions spécifiées.
Init(title.s, x.i, y.i, w.i, h.i, flags.i)Position absolue, dimensions et flags.
Init(title.s, x.i, y.i, w.i, h.i, flags.i, parent.i)Fenêtre complète avec identifiant de fenêtre parente.

Méthodes Principales

MéthodeDescription
SetRootComponent(*comp)Définit le layout racine (ex: StackPanel, DockPanel, Grid) qui se redimensionnera automatiquement.
SetTitle(t.s) / GetTitle()Modifie ou récupère le titre de la fenêtre.
SetSize(w.i, h.i)Redimensionne dynamiquement la fenêtre.
OnClose()Méthode virtuelle appelée à la fermeture de la fenêtre.
OnResize()Méthode virtuelle appelée lors du redimensionnement.
