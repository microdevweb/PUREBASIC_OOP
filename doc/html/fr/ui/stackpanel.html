Classe StackPanel

Layout

Disposition linéaire automatique verticale ou horizontale avec espacements.

Description

La classe UI::Layouts::StackPanel empile ses composants enfants selon une orientation linéaire (verticale ou horizontale) avec espacement configurable (Spacing).

Chaque enfant respecte ses marges (Margin) et ses alignements (Left, Center, Right, Stretch).

Exemple d'Utilisation

StackPanel Vertical (.pbo)PBO
Define *panel.StackPanel = New StackPanel(#UI_Orientation_Vertical, 10)
*panel\\SetPaddingAll(15)
*panel\\AddChild(New Button('Premier Bouton'))
*panel\\AddChild(New Button('Deuxième Bouton'))
*win\\SetContent(*panel)
