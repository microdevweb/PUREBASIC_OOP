Classe StackPanel

Layout

Disposition linéaire automatique verticale ou horizontale avec espacements.

Description

La classe UI::Layouts::StackPanel dispose ses composants enfants sur une seule ligne séquentielle, orientée soit verticalement (de haut en bas), soit horizontalement (de gauche à droite).

Un espacement constant (Spacing) peut être configuré entre chaque élément consécutif.

Constantes d'Orientation

ConstanteValeurDescription
#UI_Orientation_Vertical0Empilement vertical (par défaut). Les éléments s'étirent sur toute la largeur disponible.
#UI_Orientation_Horizontal1Alignement horizontal côte à côte. Idéal pour les barres d'outils ou barres d'actions.

Constructeurs & Méthodes

MéthodeDescription
Init()Crée un StackPanel vertical avec un espacement de 0 pixel.
Init(orientation.i)Crée un StackPanel avec l'orientation choisie (Verticale ou Horizontale).
Init(orientation.i, spacing.i)Crée un StackPanel avec orientation et espacement personnalisés entre chaque enfant.
SetOrientation(orient.i)Modifie dynamiquement l'orientation (#UI_Orientation_Vertical ou #UI_Orientation_Horizontal).
GetOrientation()Retourne l'orientation actuelle.
SetSpacing(sp.i)Définit l'espacement en pixels entre les éléments.
GetSpacing()Retourne l'espacement actuel.

Exemple : Formulaire Vertical & Barre d'Actions

StackPanels imbriqués (.pbo)PBO
Using UI
Using UI::Layouts
Using UI::Controls

; Panneau principal vertical avec 10px d'espacement
Define *mainStack.StackPanel = New StackPanel(#UI_Orientation_Vertical, 10)
*mainStack\\SetPaddingAll(20)

Define *txtNom.TextBox = New TextBox(0, 0, 300, 32, 'Entrez votre nom')
Define *txtEmail.TextBox = New TextBox(0, 0, 300, 32, 'Entrez votre email')
*mainStack\\AddChild(*txtNom)
*mainStack\\AddChild(*txtEmail)

; Barre de boutons horizontale en bas
Define *btnBar.StackPanel = New StackPanel(#UI_Orientation_Horizontal, 8)
*btnBar\\AddChild(New Button('Valider', 100, 35))
*btnBar\\AddChild(New Button('Annuler', 100, 35))
*mainStack\\AddChild(*btnBar)

*win\\SetContent(*mainStack)
