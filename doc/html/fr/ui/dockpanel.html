Classe DockPanel

Layout

Ancrage périphérique sur les 4 bords avec remplissage central automatique.

Description

La classe UI::Layouts::DockPanel ancre ses contrôles sur les 4 bords de l'espace disponible (#UI_Dock_Top, #UI_Dock_Bottom, #UI_Dock_Left, #UI_Dock_Right) et remplit automatiquement l'espace résiduel au centre (#UI_Dock_Fill ou LastChildFill).

Exemple : En-tête, Barre latérale et Zone centrale

Mise en page d'application moderne (.pbo)PBO
Define *dock.DockPanel = New DockPanel(#True)
*dock\\SetDock(*menuBar, #UI_Dock_Top)
*dock\\SetDock(*statusBar, #UI_Dock_Bottom)
*dock\\SetDock(*sideNav, #UI_Dock_Left)
*dock\\SetDock(*mainEditor, #UI_Dock_Fill)
*win\\SetContent(*dock)
