Classe DockPanel

Layout

Ancrage périphérique sur les 4 bords avec remplissage central automatique.

Description

La classe UI::Layouts::DockPanel ancre ses composants enfants le long de ses 4 bordures extérieures (Haut, Bas, Gauche, Droite) et attribue automatiquement tout l'espace résiduel au centre à son dernier enfant (propriété LastChildFill).

C'est le conteneur idéal pour structurer l'architecture globale d'une application professionnelle (menu en haut, barre d'état en bas, barre d'outils à gauche, zone de travail au centre).

Constantes d'Ancrage

ConstanteValeurDescription
#UI_Dock_Top0Ancre le composant en haut en occupant toute la largeur disponible.
#UI_Dock_Bottom1Ancre le composant en bas en occupant toute la largeur disponible.
#UI_Dock_Left2Ancre le composant à gauche sur la hauteur résiduelle.
#UI_Dock_Right3Ancre le composant à droite sur la hauteur résiduelle.
#UI_Dock_Fill4Remplissage automatique : occupe la totalité de l'espace central disponible.

Méthodes Principales

MéthodeDescription
Init(lastChildFill.b = #True)Crée un DockPanel avec activation ou non du remplissage central automatique pour le dernier enfant.
SetDock(*child, dockEdge.i)Attache un enfant et lui assigne son bord d'ancrage (#UI_Dock_Top, #UI_Dock_Bottom, etc.).
GetDock(*child)Renvoie la valeur d'ancrage actuelle du composant.
SetLastChildFill(fill.b)Active (#True) ou désactive (#False) l'agrandissement automatique du dernier enfant.
GetLastChildFill()Retourne l'état de la propriété LastChildFill.

Exemple : Architecture Complète d'Application

Mise en page complète avec DockPanel (.pbo)PBO
Define *root.DockPanel = New DockPanel(#True)
*root\\SetPaddingAll(5)

; 1. En-tête fixé en haut
Define *header.StackPanel = New StackPanel(#UI_Orientation_Horizontal, 5)
*header\\SetHeight(40)
*root\\SetDock(*header, #UI_Dock_Top)

; 2. Barre d'état fixée en bas
Define *status.Label = New Label(0, 0, 400, 25, 'Prêt')
*root\\SetDock(*status, #UI_Dock_Bottom)

; 3. Navigation latérale à gauche
Define *nav.StackPanel = New StackPanel(#UI_Orientation_Vertical, 6)
*nav\\SetWidth(180)
*root\\SetDock(*nav, #UI_Dock_Left)

; 4. Zone centrale de travail (Fill automatique)
Define *editor.TextBox = New TextBox(0, 0, 100, 100, 'Document...')
*root\\SetDock(*editor, #UI_Dock_Fill)

*win\\SetContent(*root)
