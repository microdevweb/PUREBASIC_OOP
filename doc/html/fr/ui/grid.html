Classe Grid

Layout

Grille responsive 2D avec dimensionnement en pixels, Auto et Star (*).

Description

La classe UI::Layouts::Grid définit une grille 2D flexible en lignes et colonnes, avec dimensionnement en pixels, "Auto" ou proportionnel Star ("*", "2*").

Constructeurs Surchargés

ConstructeurDescription
Init()Grille 2D réactive par défaut.
Init(w.i, h.i)Grille 2D avec dimensions initiales.

Exemple d'utilisation

Grille avec Star Sizing (.pbo)PBO
Define *grid.Grid = New Grid()
*grid\AddColumn("200")  ; Colonne 0: 200px fixe
*grid\AddColumn("3*")   ; Colonne 1: 75% largeur restante
*grid\AddColumn("1*")   ; Colonne 2: 25% largeur restante
*grid\AddRow("50")      ; Ligne 0: 50px en-tête
*grid\AddRow("*")       ; Ligne 1: Contenu fluide

*grid\SetCell(*sidebar, 0, 0, 2, 1) ; RowSpan=2
*grid\SetCell(*mainView, 1, 1)
*win\SetRootComponent(*grid)
