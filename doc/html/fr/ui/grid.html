Classe Grid

Layout

Grille bidimensionnelle responsive avec unités fixes, Auto et proportionnelles (*).

Description

La classe UI::Layouts::Grid définit une grille flexible à 2 dimensions composée de lignes et de colonnes. Inspirée de WPF, elle supporte 3 modes de dimensionnement puissants :

  • Pixels fixes : '150' ou '200px'.
  • Automatique : 'Auto' (s'adapte au contenu désiré).
  • Proportionnel (Star Sizing) : '*', '2*', '3*' (partage dynamique et fluide de l'espace résiduel).

Elle supporte également la fusion de cellules sur plusieurs lignes et colonnes via SetCellSpan(child, rowSpan, colSpan).

Exemple de Grille Responsive

Grille avec Star Sizing (.pbo)PBO
Define *grid.Grid = New Grid()
*grid\\AddColumn('200')  ; Colonne 0 : 200px fixe
*grid\\AddColumn('3*')   ; Colonne 1 : 75% du reste
*grid\\AddColumn('1*')   ; Colonne 2 : 25% du reste
*grid\\AddRow('50')      ; Ligne 0 : 50px fixe
*grid\\AddRow('*')       ; Ligne 1 : Hauteur fluide

*grid\\SetCell(*sidebar, 0, 0, 2, 1) ; RowSpan=2
*grid\\SetCell(*mainView, 1, 1)
*win\\SetContent(*grid)
