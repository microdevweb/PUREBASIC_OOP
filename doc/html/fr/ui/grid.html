Classe Grid

Layout

Grille bidimensionnelle responsive avec unités fixes, Auto et proportionnelles (*).

Description

La classe UI::Layouts::Grid définit une zone de mise en page sous forme de tableau bidimensionnel composé de lignes (Rows) et de colonnes (Columns). C'est le conteneur de disposition le plus puissant et flexible de PureBasic OOP.

Inspirée directement du moteur WPF de Microsoft, elle supporte 3 modes de dimensionnement pour chaque ligne et colonne :

  • Pixels fixes (Absolute) : Une valeur numérique comme '150' ou '200px' réserve une taille exacte et constante.
  • Automatique (Auto) : La chaîne 'Auto' adapte automatiquement la largeur/hauteur en fonction de la taille demandée par les composants enfants de la cellule.
  • Proportionnel (Star Sizing *) : Les définitions comme '*', '2*', '3*' partagent dynamiquement tout l'espace restant après attribution des tailles fixes et Auto. Par exemple, '3*' et '1*' attribuent 75% et 25% de la largeur résiduelle.

Fusion de Cellules (RowSpan & ColSpan)

Un composant peut occuper plusieurs cellules adjacentes grâce aux paramètres rowSpan et colSpan de la méthode SetCell ou via SetCellSpan.

Méthodes Principales de Grid

MéthodeParamètresDescription
Init()AucunInitialise une nouvelle grille vide sans lignes ni colonnes.
AddColumn(def.s)'150', 'Auto', '*', '2*'...Ajoute une colonne à droite avec la définition de dimension spécifiée.
AddRow(def.s)'40', 'Auto', '*', '3*'...Ajoute une ligne en bas avec la définition de dimension spécifiée.
SetCell(*child, row, col, [rowSpan], [colSpan])*child, r.i, c.i, rs.i=1, cs.i=1Place un composant dans la cellule à la ligne row et colonne col (indexées à partir de 0).
SetCellSpan(*child, rowSpan.i, colSpan.i)*child, rs.i, cs.iModifie l'étendue d'un enfant sur plusieurs lignes et colonnes.
ClearDefinitions()AucunRéinitialise toutes les définitions de lignes et colonnes.
GetColumnCount()Retourne .iRenvoie le nombre de colonnes définies.
GetRowCount()Retourne .iRenvoie le nombre de lignes définies.

Exemple : Grille Responsive Éditeur + Volet d'Inspection

Grille WPF avec Star Sizing et ColSpan (.pbo)PBO
Define *grid.Grid = New Grid()
*grid\\SetPaddingAll(8)

; Colonnes : Barre latérale (180px fixe), Zone centrale (3* soit 75%), Volet droit (1* soit 25%)
*grid\\AddColumn('180')
*grid\\AddColumn('3*')
*grid\\AddColumn('1*')

; Lignes : Barre d'outils (40px fixe), Zone de contenu fluide (*)
*grid\\AddRow('40')
*grid\\AddRow('*')

; Ligne 0 : Barre de recherche fusionnée sur 2 colonnes (ColSpan=2)
Define *search.TextBox = New TextBox(0, 0, 100, 30, 'Recherche...')
*grid\\SetCell(*search, 0, 1, 1, 2) ; Row 0, Col 1, ColSpan 2

; Colonne 0 : Menu latéral occupant les 2 lignes (RowSpan=2)
Define *sidebar.StackPanel = New StackPanel(#UI_Orientation_Vertical, 5)
*grid\\SetCell(*sidebar, 0, 0, 2, 1) ; Row 0, Col 0, RowSpan 2

; Ligne 1 : Zone d'édition principale (Col 1) et Propriétés (Col 2)
Define *mainEditor.TextBox = New TextBox(0, 0, 100, 100, 'Éditeur de code')
Define *propPanel.TextBox = New TextBox(0, 0, 100, 100, 'Propriétés')
*grid\\SetCell(*mainEditor, 1, 1)
*grid\\SetCell(*propPanel, 1, 2)

*win\\SetContent(*grid)
