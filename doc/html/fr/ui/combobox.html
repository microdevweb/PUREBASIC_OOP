Classe ComboBox

UI Class

Liste déroulante avec multi-constructeurs et sélection d'éléments.

🖇 Hiérarchie d'héritage
Core::Object → UI::Component → UI::Gadget → UI::ComboBox
Méthodes héritées de UI::Gadget (7 méthodes)
GetID() GetHandle() SetFont() SetColor() FreeGadget() SetToolTip() SetFocus()
Méthodes héritées de UI::Component (8 méthodes)
SetPosition() SetSize() SetMargin() SetHorizontalAlignment() SetVerticalAlignment() SetVisible() SetEnabled() Arrange()

Description

La classe UI::ComboBox encapsule une liste déroulante avec ajout d'éléments, sélection d'index et événement OnSelect().

Constructeurs Surchargés

ConstructeurDescription
Init()ComboBox par défaut positionné par les layouts.
Init(w.i, h.i)ComboBox avec dimensions souhaitées.
Init(x.i, y.i, w.i, h.i)ComboBox avec coordonnées absolues et dimensions.
Init(x.i, y.i, w.i, h.i, flags.i)ComboBox complet avec flags PureBasic.

Méthodes Spécifiques

MéthodeDescription
AddItem(item.s)Ajoute un élément à la liste déroulante.
GetSelectedIndex() / SetSelectedIndex(idx.i)Obtient ou définit l'index de l'élément sélectionné.
GetSelectedText()Retourne le texte de l'élément sélectionné.
Clear()Vide l'ensemble des éléments de la liste.
OnSelect()Méthode virtuelle appelée lors d'un changement de sélection.
