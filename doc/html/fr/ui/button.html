Classe Button

UI Class

Contrôle bouton poussoir cliquable avec multi-constructeurs et gestion d'événements.

🖇 Hiérarchie d'héritage
Core::Object → UI::Component → UI::Gadget → UI::Button
Méthodes héritées de UI::Gadget (7 méthodes)
GetID() GetHandle() SetFont(fontID) SetColor(type, color) FreeGadget() SetToolTip(tip) SetFocus()
Méthodes héritées de UI::Component (8 méthodes)
SetPosition(x, y) SetSize(w, h) SetMargin(l, t, r, b) SetHorizontalAlignment(align) SetVerticalAlignment(align) SetVisible(v) SetEnabled(e) Arrange()

Description

La classe UI::Button encapsule un bouton poussoir cliquable PureBasic avec gestion directe de l'événement virtuel OnClick() et prise en charge des layouts réactifs.

Constructeurs Surchargés

ConstructeurDescription
Init()Bouton par défaut sans texte (dimensions gérées par les layouts).
Init(text.s)Bouton avec texte, dimensions calculées par les layouts.
Init(text.s, w.i, h.i)Bouton avec texte et dimensions souhaitées.
Init(text.s, x.i, y.i, w.i, h.i)Bouton avec texte, position absolue et dimensions.
Init(text.s, x.i, y.i, w.i, h.i, flags.i)Bouton complet avec flags PureBasic ButtonGadget.

Méthodes Spécifiques

MéthodeDescription
GetText() / SetText(txt.s)Obtient ou modifie le texte du bouton.
OnClick()Méthode virtuelle appelée lors du clic utilisateur.
