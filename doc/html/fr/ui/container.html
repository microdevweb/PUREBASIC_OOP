Classe Container

Layout

Classe de base pour tous les panneaux de disposition responsive WPF.

Description

La classe UI::Layouts::Container est la classe abstraite de base pour tous les conteneurs et panneaux de mise en page responsives. Inspirée du modèle WPF / .NET, elle orchestre le cycle de mise en page automatique en deux passes : Measure et Arrange.

Elle gère la collection d'enfants (composants graphiques et sous-panneaux imbriqués) ainsi que les marges internes (Padding).

Méthodes Principales

MéthodeDescription
AddChild(*child.Component)Ajoute un composant enfant à la collection du conteneur.
RemoveChild(*child.Component)Retire un composant de la collection.
ClearChildren()Supprime et libère tous les enfants attachés.
SetPadding(l.i, t.i, r.i, b.i)Définit les marges intérieures (gauche, haut, droite, bas) en pixels.
SetPaddingAll(p.i)Applique une marge intérieure uniforme sur les 4 côtés.
Arrange(x.i, y.i, w.i, h.i)Exécute le calcul et le positionnement dynamique de tous les enfants dans la zone allouée.
