CanvasTable Class

CANVAS

High-performance vector data table (DataGrid) featuring virtual scrolling, resizable sorted columns, and interactive cells.

Overview

UI::CanvasTable inherits from UI::CanvasControl and provides an ultra-responsive 2D vector data grid. Built for rendering and interacting with large datasets smoothly using virtual scrolling, it natively provides column sorting and resizing, alternating row colors (light and dark palettes), inline cell editing, and multiple column types (text, numbers, floats, checkboxes, action buttons, and icons).
