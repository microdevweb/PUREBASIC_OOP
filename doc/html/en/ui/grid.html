Grid Class

Layout

Two-dimensional responsive layout grid with fixed, Auto and Star (*) proportional sizing.

Description

The UI::Layouts::Grid defines a flexible 2D grid area consisting of rows and columns. Inspired by WPF, it supports 3 robust sizing modes:

  • Fixed Pixels: '150' or '200px'.
  • Auto Sizing: 'Auto' (contracts/expands to fit child content).
  • Proportional Star Sizing: '*', '2*', '3*' (dynamically partitions available space).

Child elements can span multiple rows and columns using SetCellSpan(child, rowSpan, colSpan).

Usage Example

Responsive Star Grid (.pbo)PBO
Define *grid.Grid = New Grid()
*grid\\AddColumn('200')  ; Column 0: 200px fixed
*grid\\AddColumn('3*')   ; Column 1: 75% of remaining width
*grid\\AddColumn('1*')   ; Column 2: 25% of remaining width
*grid\\AddRow('50')      ; Row 0: 50px header
*grid\\AddRow('*')       ; Row 1: Fluid content

*grid\\SetCell(*sidebar, 0, 0, 2, 1) ; RowSpan=2
*grid\\SetCell(*mainView, 1, 1)
*win\\SetContent(*grid)
