Grid Class

WPF Layout

Two-dimensional responsive layout grid with Star (*) proportional sizing.

Description

The UI::Layouts::Grid arranges elements in flexible 2D rows and columns with fixed pixel, "Auto", and Star ("*", "2*") proportional sizing.
