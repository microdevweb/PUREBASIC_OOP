Window Class

Core UI

Native event-driven window with automated root layout resizing and event loop.

🖇 Inheritance Hierarchy
Core::Object → UI::Window

Description

The UI::Window class encapsulates a native PureBasic window (OpenWindow) with automated root layout resizing, message dispatching, and unified event routing.

Overloaded Constructors

ConstructorDescription
Init()Default window (800x600, centered).
Init(title.s, w.i, h.i)Window with title and dimensions, screen-centered.
Init(title.s, x.i, y.i, w.i, h.i)Window with title, position, and dimensions.
Init(title.s, x.i, y.i, w.i, h.i, flags.i)Full window with PureBasic OpenWindow flags.
