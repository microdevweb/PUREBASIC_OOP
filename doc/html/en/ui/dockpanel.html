DockPanel Class

Layout

Edge-docking layout panel with automatic central filling.

Description

The UI::Layouts::DockPanel positions child elements along its 4 outer edges (#UI_Dock_Top, #UI_Dock_Bottom, #UI_Dock_Left, #UI_Dock_Right) and automatically expands the last child to fill all remaining central space (#UI_Dock_Fill or LastChildFill).

Usage Example: Modern App Shell

Full Application Shell Layout (.pbo)PBO
Define *dock.DockPanel = New DockPanel(#True)
*dock\\SetDock(*toolbar, #UI_Dock_Top)
*dock\\SetDock(*statusBar, #UI_Dock_Bottom)
*dock\\SetDock(*sideNav, #UI_Dock_Left)
*dock\\SetDock(*mainEditor, #UI_Dock_Fill)
*win\\SetContent(*dock)
