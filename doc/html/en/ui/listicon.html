ListIcon Class

UI Class

Multi-column tabular data grid with overloaded constructors.

🖇 Inheritance Hierarchy
Core::Object → UI::Component → UI::Gadget → UI::ListIcon

Inherited Methods de UI::Component (8 méthodes)
SetPosition() SetSize() SetMargin() SetHorizontalAlignment() SetVerticalAlignment() SetVisible() SetEnabled() Arrange()

Description

The UI::ListIcon class wraps a native multi-column ListIconGadget to display tabular data records with selection and double-click event handling.

Overloaded Constructors

ConstructorDescription
Init()Default ListIcon arranged by layout panels.
Init(firstColTitle.s, firstColWidth.i)ListIcon initialized with first column title and width.
Init(firstColTitle.s, firstColWidth.i, w.i, h.i)ListIcon with first column and preferred dimensions.
Init(x.i, y.i, w.i, h.i, firstColTitle.s, firstColWidth.i, flags.i)Full ListIcon with absolute coordinates and flags.

Specific Methods

MethodDescription
AddColumn(colIndex.i, title.s, width.i)Adds a new column header.
AddItem(index.i, text.s)Inserts a data row (columns separated by Chr(10)).
GetSelectedIndex() / SetSelectedIndex(idx.i)Gets or sets the selected row index.
GetItemText(index.i, col.i)Returns text content of a specific cell.
Clear()Removes all rows.
OnSelect() / OnDoubleClick()Virtual methods triggered on row selection or double-click.
