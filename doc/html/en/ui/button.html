Button Class

UI Class

Clickable pushbutton control with overloaded constructors and event handling.

Description

The UI::Button class wraps a native pushbutton with responsive layout arrangement and virtual OnClick() event routing.

Overloaded Constructors

ConstructorDescription
Init()Default button without text (bounds managed by layout panels).
Init(text.s)Button with caption, sized by layout panels.
Init(text.s, w.i, h.i)Button with caption and preferred dimensions.
Init(text.s, x.i, y.i, w.i, h.i)Button with caption, absolute coordinates, and dimensions.
Init(text.s, x.i, y.i, w.i, h.i, flags.i)Full button with PureBasic ButtonGadget flags.

Specific Methods

MethodDescription
GetText() / SetText(txt.s)Gets or sets the button caption.
OnClick()Virtual method triggered on user click.
