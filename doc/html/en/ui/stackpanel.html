StackPanel Class

Layout

Linear vertical or horizontal layout panel with automatic spacing.

Description

The UI::Layouts::StackPanel arranges child elements into a single line that can be oriented horizontally or vertically, with configurable spacing between items.

Each child component respects its own margins (Margin) and alignment constraints (Left, Center, Right, Stretch).

Usage Example

Vertical StackPanel (.pbo)PBO
Define *panel.StackPanel = New StackPanel(#UI_Orientation_Vertical, 10)
*panel\\SetPaddingAll(15)
*panel\\AddChild(New Button('First Button'))
*panel\\AddChild(New Button('Second Button'))
*win\\SetContent(*panel)
