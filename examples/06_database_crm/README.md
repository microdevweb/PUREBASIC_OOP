# 06 - Database CRM Demo

This example demonstrates the **PureBasic OOP Alpha 1.4 Modern ORM Engine** with a Customer/Contact CRM.

## What It Shows

| Feature | How |
|---|---|
| Entity Classes | `Class Contact Implement IDatabaseEntity` |
| Relations 1-N | `HasMany contacts.Contact` inside `Class Client` |
| Zero boilerplate | Serialization, Deserialization, and CRUD methods auto-generated by the transpiler |
| Auto table creation | `*db\AutoMigrate()` creates `clients` and `contacts` tables automatically |
| Active Record Save | `*client\Save()` saves client and cascades to save all attached contacts |
| Contextual Save | `*client\Save(*db)` or `*db\Save(*client)` supported |
| Schema migration | Adding a field to an entity class auto-creates column on next run |

## How to Run

1. Source file: `main.pbo`
2. Transpile: `.\compiler\transpiler.exe examples\06_database_crm\main.pbo examples\06_database_crm\main.pb .`
3. Compile & Run: `& "pbcompiler.exe" /CONSOLE examples\06_database_crm\main.pb /EXE examples\06_database_crm\main.exe`
4. Run `.\examples\06_database_crm\main.exe`
5. A file `crm_demo.db` is created in the same folder verifying automatic schema & cascade persistence.

## Files

- `main.pbo` — PureBasic OOP Source using native `Class ... Implement IDatabaseEntity` & `HasMany`
- `main.pb` — Transpiled native PureBasic source file
- `crm_demo.db` — SQLite database (created at runtime)

## Cascade Rules Configured in This Demo

```purebasic
relations()\cascadeSave  = #True            ; SaveAsync(client) saves all contacts
relations()\deletePolicy = #ORM_Restrict_Delete  ; Cannot delete client with contacts
```

To allow cascade delete instead, change to:
```purebasic
relations()\deletePolicy = #ORM_Cascade_Delete
```

## Testing Multi-Station Locking

To simulate two workstations:
1. Run the application twice simultaneously
2. In window 1: add a client, save it, then click **Lock Record**
3. In window 2: select the same client id and click **Lock Record**
4. Window 2 should display: _"This record is being edited by [user] on [station]"_
5. Close window 1 without clicking Unlock
6. Wait 60 seconds
7. In window 2: click **Lock Record** again — it now succeeds (lease expired)
